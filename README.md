# Ultimate GD Toolbox v0.1.0

This package is specifically targeted at:

- Geode v5.10.1
- Geometry Dash 2.2081
- Android 64-bit / arm64-v8a

The manifest uses the exact Geode version format required by Geode:
`v5.10.1`.

Build:

```text
geode build -p android64
```

If the build fails, send the complete first error block rather than changing
the manifest version manually.
